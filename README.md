# URnetwork language examples

Install the SDK and use userspace sockets from each supported language. Every language has an installation README and executable programs under `socket/`, with a `socket/README.md` covering setup, HTTP client integration and primary-source references. JavaScript includes separate Node and browser programs.

The new package coordinates and socket release are being prepared. Guides distinguish public installation targets from locally built packages. Local proxy recipes preserve a kernel loopback hop while routing destination connections through the Device.
